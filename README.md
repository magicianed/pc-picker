# PC Picker

A price slider that shows the best gaming PC I found at each price point.

Everything is in `index.html`. To change a PC, edit its entry in the `PCS` list.

**Performance score:** an estimate, not a benchmark. Each PC gets
`GPU^0.7 x CPU^0.3 x memory factor`, using rough relative speeds from reviews,
then the fastest PC is set to 100. The percentage is compared with the cheapest PC.

Prices are before tax and were checked on Nov 24, 2026.
